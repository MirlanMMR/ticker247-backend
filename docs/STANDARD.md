# ЭТАЛОН ленты Ticker 24/7 (черновик на утверждение владельцем, 04.11.2026)

Одно место, где записано, **какой должна быть лента**. Любое несоответствие — красный флаг
(`python standard_check.py`). Чинить — по разделу 10. Новые находки владельца — строкой сюда в тот же день.

**Как читать.** У правила есть номер `S-…`, замок и исполнитель.
Замок: ✅ детектор есть и запущен · 🟡 детектор есть, но не в конвейере/режим «тень» · ⛔ замка нет (правило без замка не считается закрытым).
Определения (полки, событие, срочно) **не копируются**: они живут в `EDITORIAL.md` — единственное место (владелец, 17.10).
Номера `J…` — строки `docs/defects_journal.md`.

## 10. Кто чинит (одно правило для всех)

1. **Сторож** (код, без ИИ) — после последнего шага, до записи. Устраняет механически: берёт текст/заголовок источника как есть (правило 4), снимает карточку с чужой полки или с нарушением метки, добирает полку из запаса. Включается для правила, когда оно утверждено владельцем и имеет замок.
2. **Дежурный агент** — если сторож не справился: задача с карточкой и номером правила, агент открывает PR в бэкенд (облачный контур уже работает).
3. **Владелец** — только если не справился и агент, или менять сам эталон.
Правку принимает эталон, а не тест того, кто правил: доля нарушений должна уменьшиться (CLAUDE.md, правило 2).
